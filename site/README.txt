# Mugi Gelato — Yeni Ana Sayfa

Bu klasör mevcut Mugi Gelato içeriği temel alınarak hazırlanmış, sade/premium ve responsive bir ana sayfa taslağıdır.

## Dosyalar
- index.html
- style.css
- script.js
- images/

## Görseller
`images/` klasörüne şu dosyaları koy:
- hero.jpg
- gelato-detail.jpg
- story.jpg

Mevcut Mugi sitesindeki görselleri kendi dosyalarınla değiştirmen yeterli.

## Çalıştırma
index.html dosyasını tarayıcıda açabilirsin. Sunucu gerekiyorsa VS Code Live Server gibi basit bir local server kullanılabilir.

## Tasarım
- Krem / kırık beyaz / koyu kahve tabanlı palet
- Playfair Display + DM Sans
- Responsive mobil menü
- Scroll'da küçülen/arka plan alan navbar
- Yorum sliderı + mobil swipe
- Smooth anchor navigation
- Mevcut Mugi metinleri ve iletişim bilgileri korunarak yeniden düzenlendi
